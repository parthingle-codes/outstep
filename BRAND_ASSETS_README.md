# OutStep brand assets

These assets derive from the approved OutStep leaf-and-sun logo. The icon mark intentionally excludes the wordmark and any footprints/step trail.

Files:
- `frontend/public/outstep-logo-full.png` — full logo and wordmark (transparent rounded outer corners).
- `frontend/public/outstep-mark.png` — large square leaf-and-sun mark.
- `frontend/public/pwa-192x192.png` — standard PWA icon.
- `frontend/public/pwa-512x512.png` — standard PWA icon.
- `frontend/public/pwa-maskable-512x512.png` — maskable PWA icon with extra safe-area padding.
- `frontend/public/apple-touch-icon.png` — iOS home-screen icon.
- `frontend/public/favicon-32x32.png` — favicon.

Suggested palette sampled/approximated from the approved art: forest green `#0E3B2E`, leaf green `#4F7E3F`, moss green `#A7C957`, warm sun `#F8C96A`, cream `#FFFEF7`. Treat these as practical UI reference colours rather than exact source-vector values.
